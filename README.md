# Calamity Archival Pack + Dependencies
This repository is meant to keep a lot of Calamity mod content and add-ons easily available, getting updates whenever any mod gets an update.

### How-to
- First things first, you'll need to head over to the "Releases" tab and download the latest .zip that's uploaded.
- Afterward, you'll want to extract the files so that you have all the .tmod files available to copy.
- Once that's done, you'll need to go to "C:\Users\[User]\Documents\My Games\Terraria\tModLoader\Mods" in a separate tab in file explorer ([User] being your desktop username)
- Once both tabs are set, copy and paste the .tmod files from the mods.zip extraction into the tmod mods folder
- Lastly, enjoy the mods locally installed into tmodloader!
